Token de API

Pra puxar dados deste sistema por fora do navegador (scripts, Postman, Power Query do Excel, etc.) — veja as rotas disponíveis na documentação da API. Cada token vale por 90 dias; gerar um novo não invalida os anteriores, cada um expira sozinho no seu prazo.

Ver documentação da API

Use como Authorization: Bearer <token> nas chamadas — guarde num lugar seguro, quem tiver esse token acessa os dados desta conta.
