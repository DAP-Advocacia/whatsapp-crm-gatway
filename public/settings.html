Configurações

Preferências gerais desta instalação — hoje só a paleta de cores, mas é aqui que futuras configurações globais entram.

Modelos prontos

Aplica a paleta inteira de um clique só (inspirados em apps conhecidos, como o WhatsApp). Depois de escolher um, ainda dá pra ajustar qualquer cor à mão logo abaixo.

Cor de destaque

Substitui o dourado padrão em todas as telas internas e nas páginas públicas das LPs (quando a própria LP não tiver uma cor própria configurada). Se você nunca mexer aqui, o app continua com a cor padrão de sempre.

Cole um código hex (ex: #2e6b52) ou use o seletor.

Desmarque a caixa acima pra escolher essa cor você mesmo.

O fundo dos cards/painéis (as "superfícies") clareia sozinho a partir dessa cor — não precisa escolher à parte.

Token de API

Pra puxar dados deste sistema por fora do navegador (scripts, Postman, Power Query do Excel, etc.) — veja as rotas disponíveis na documentação da API. Cada token vale por 90 dias; gerar um novo não invalida os anteriores, cada um expira sozinho no seu prazo.

Ver documentação da API

Use como Authorization: Bearer <token> nas chamadas — guarde num lugar seguro, quem tiver esse token acessa os dados desta conta.
