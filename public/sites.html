Use {{nome}} pra personalizar com o nome preenchido.

Se deixar em branco, é gerada automaticamente a partir do nome.

Cole o link de uma imagem já hospedada, ou envie um arquivo (JPG/PNG/WEBP/GIF, até 6MB).

Foto (JPG/PNG/WEBP/GIF, até 6MB) ou vídeo (MP4/WEBM/MOV, até 25MB) de fundo do banner no topo da página pública. Colar um link de vídeo já hospedado também funciona, mas só reconhece a extensão automaticamente (.mp4/.webm/.mov) — enviando o arquivo aqui não tem esse risco.

Números de destaque (ex: "500+" / "clientes atendidos") — até 4. A seção só aparece se houver ao menos um.

Perguntas e respostas — até 8. A seção só aparece se houver ao menos uma.
